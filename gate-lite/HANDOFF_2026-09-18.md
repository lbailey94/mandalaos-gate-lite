## 3. Known deviations / gotchas (also contract §14)

- `systemd-run --pipe` captures stdout; on systemd 255 a signal-killed payload
  reports `rc=0/success` through `--pipe` — operator kills are proven by the
  kill request + termination receipt + latency.
- MCP HTTP handler sets `TCP_NODELAY` (benchmark: keep-alive ping 41 ms →
  0.42 ms). Operator kill sends SIGTERM then escalates to SIGKILL after a 1 s
  grace (benchmark: p95 5.1 s → 1.1 s; SIGTERM alone can be missed during
  sandbox startup, SIGKILL always lands).
- Desktop OOM notifications: bench OOM drills (and the G2 acceptance tests)
  kill payloads via memcg OOM, which makes `gsd-housekeeping` show
  "Application Stopped / memory nearly full" popups. The bench drill is now
  opt-in (`--oom`); there is no gsettings toggle for the notification.
- `CPUQuota` throttles; memory and wall are the kill dimensions.
- HTTP transport is loopback-only, no TLS; `--token` optional.
- **Workspace `rw: true` requires the updated host wrapper.** If the wrapper
  is replaced/reinstalled from the sovereign module, mirror this change
  (additive: envelope `rw` → `--bind` instead of `--ro-bind`).
- Redaction rewrites signatures: `disclose redact` needs the issuer key and
  re-signs the chain tail from the first modified receipt (issuance-time act).
- `~/.local/bin/wm` still not reachable inside the sandbox (no bind for it);
  a `ro_binds` envelope field would generalize this when wanted.
