# Contributing

This repository is a curated **review snapshot**, not the active MandalaOS
development tree. Contributions that fit the snapshot's purpose are welcome:

- **Review findings** — open an issue with `file:line` references and a
  reproducer. [`REVIEW_NOTES.md`](REVIEW_NOTES.md) lists the questions and
  attacks the maintainer most wants examined; honest failure reports are
  wanted, not polish.
- **Doc corrections** — claim drift between `README.md`/`design/` and the
  code is a first-class bug here; report it as such.
- **Pull requests** — small, reviewable fixes are accepted; by submitting you
  agree your contribution is licensed under the repository's MIT license.
- **Receipt-format changes** — belong in
  [continuity-receipt](https://github.com/lbailey94/continuity-receipt), not
  here.

Security reports: see [`SECURITY.md`](SECURITY.md) for the private channel.

AI-assisted contributions are acceptable when disclosed and reviewable; the
human submitter is accountable for every claim in the contribution.
